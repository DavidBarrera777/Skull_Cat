# Skull_Cat
Basic game demonstration using py game.

Upon running the .py file a start menu is prompted.
<img width="718" height="471" alt="2025-11-13 15_11_32-SkullCat" src="https://github.com/user-attachments/assets/d0990bbe-4cc2-4ada-9b3a-2ba7a13e80cd" />

Upon clicking the start button with the mouse you are prompted to avoid the ground objects by jumping with the space bar and dodging flying objects by staying still.
<img width="720" height="473" alt="image" src="https://github.com/user-attachments/assets/698596d5-9a69-4a36-8b6e-5fdb08023f8d" />
<img width="720" height="472" alt="image" src="https://github.com/user-attachments/assets/e592daa5-ac5d-49e3-8212-abb78ad2b055" />

Upon getting hit by either objects you are prompted to a death screen animation where you can restart the game by pressing the space bar.
